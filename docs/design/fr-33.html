Match CSV columns

Learners import the CSV files they already have, whatever their column names (kosakata, arti, cara baca). After a file is picked, the import modal you already know gets one more field, “Match columns”: each column name of the file with a dropdown for its Voca field. Only Term and Meaning are required. A column left on “Not imported” is simply ignored. No file sends two columns to one field: in Import CSV, picking a field that another column has moves it there; in Import decks, different names may share a field as long as no single file has both. Columns Voca knows by name start matched. The “Download template” link is gone, and matches are never remembered.

Kit mapping: Modal Button Select ErrorState-style alert. new component ColumnMatch: the table of column names and dropdowns; in Import decks it adds an “In” column with the file count. Dropdown options in this order: Not imported, Term, Meaning, Reading, Example, Notes. Known names that start matched: term, meaning, reading, example, notes, and hiragana / pinyin / jyutping for Reading (ignoring case and surrounding spaces). If two known names want the same field, the first column gets it.
Flow · nothing changes after Import

Where matching fits

Matching only reads each file's header row in the modal, before anything is uploaded. Import CSV stays synchronous (FR-4). Import decks still runs in the background (FR-29): the modal closes on Import, and the batch shows in the Imports panel docked bottom-right, with the same progress, per-file results, reload survival and dismiss as today.

  1. UnchangedPick filesImport CSV: one file. Import decks: up to 50 files, 50 MB in total.
  2. NewMatch columnsRead from each file's header row. Term and Meaning required; the rest optional.
  3. UnchangedImportImport decks also asks the two languages. Import is enabled once every file has a Term and a Meaning column.
  4. UnchangedResultImport CSV: the result in the modal. Import decks: the modal closes; progress and per-file results in the Imports panel (FR-29).

Import decks

The shipped modal, with “Match columns” between the files and the languages. It lists each distinct column name across the picked files once, with how many files have it, most common first; blank header cells share one “(no name)” row. A name is matched once for the whole batch, wherever it sits in each file, so 50 files cost one row per distinct name: identical headers, the same names in any order, and completely different names all work in one batch. Different names may share a field (kosakata and word both on Term) as long as no single file has both. The rules are checked per file: every file needs a Term and a Meaning column and no field on two of its columns; each problem line names its files (the first 3, then “and N more”). On Import the modal closes and the batch goes to the Imports panel, unchanged (FR-29).
